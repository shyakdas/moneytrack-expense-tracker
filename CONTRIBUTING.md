# Contributing to MoneyTrack

Thanks for your interest in contributing 🙌
MoneyTrack values **clean code, privacy, and maintainability**.

---

## 🧭 How to Contribute

### 1. Fork & Branch
- Fork the repository
- Create a branch from `main`
- Use descriptive branch names:
  - `feature/`
  - `fix/`
  - `chore/`

---

## 🧪 Before Opening a PR

Run all checks locally:

```bash
make ci
